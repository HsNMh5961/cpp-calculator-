\# C++ Calculator



A Simple Command-line Calculator written in C++ as practice project for learning Git And C++.



\##Feature

* additional ("add")
* Subtraction ("sub")
* Multiplication ("mul")
* Division ("div")
* Power ("pow")
* Square Root ("sqrt")



\## How To RUN

1.Just open main.cpp with your IDE like dev C++ or any C++ compiler 

2.Compile and Run



\## Usage Example 

... text

add 5 3

Operation number1 number2

For square root ignore number2 

sqrt 16 0 <--
